# Dano Airlines Analysis ✈️👮‍♀️

## Summary
The purpose of this analysis is to evaluate passenger survey data for Dano Airlines in order to understand the factors driving customer satisfaction and dissatisfaction. 
# Purpose
The analysis aims to identify underperforming service areas 
- Uncover patterns across passenger segments and travel types
- Gain insights into what causes satisfaction or dissatisfaction
- Provide actionable insights to help the airline improve custoner experience.

# Tools
- Microsoft Excel- charts creation
- SQL- used to query data for easy insights
- Pivot table- for summarizing, grouping, filtering,etc.
- File Format- .pdf for report

# Data source
Dataset used for this analysis includes:
- Organization operation (type of travel, flight distance, etc.)
- Demograhics (gender, age)

> _Note: This data was gotten from digitaley drive_

# Features & Highlights
 ### Problem Statement
Dano Airlines has experienced a decline in passenger satisfaction, with survey report showing a drop in satisfaction level of customers. The airline needs to nip this on the board to improve service quality and customer satisfaction. 
 ### Dashboard Goal
To provide insights 
 - Uncover satisfaction/dissatisfaction level amongst customers 
 - Provide clear,actionable recommendations to support improved quality service and customer satisfaction.

 ### Recommendations
 - Elevate Onboard Service Excellence: 
Onboard service is a primary driver of passenger satisfaction and repeat travel. Enhancements to food and beverage quality, cabin comfort, and in-flight assistance will significantly improve the overall travel experience and strengthen customer loyalty.
- Enhance Ease of Online Booking: 
A seamless digital booking experience is critical to customer satisfaction, particularly for business travelers. Simplifying the website and mobile app interface will improve navigation.
- Demographic and behavioral insights (such as age, gender, travel purpose, loyalty status, and class of service) should guide service enhancements.
- Dano Airlines should establish an ongoing feedback and performance monitoring system to track satisfaction trends across key touchpoints.
